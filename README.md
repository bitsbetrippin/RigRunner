# Rig Runner — Miner's Life · v0.3.1

Browser-based crypto-mining sim grounded in late-2015 Ethereum economics. Run GPU
rigs, solo-mine or join one of 8 pools, earn BBT, weigh hashrate vs. power bill.
Open index.html (or serve: python3 -m http.server 8000).

Network: ~381 GH/s global, player ~0.044%. 8 pools hold ~85%; solo field ~15%.
Solo = winner-take-all (swingy); pools = steady share, paid ~15min, minus fee
(smaller pools = lower fee = higher net). 10s blocks, ~4-year halving, full 5 BBT
reward. Token: BBT. Pixel art is the author's own work; this is a game.

Roadmap: shop/GPU purchasing, per-GPU sound, weather API, GPU data table,
multiple rigs, player movement, real leaderboards, save slots, server-synced chain.
